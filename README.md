# Porthen — Sales Intelligence & Lead Management

Porthen is a modern SaaS sales intelligence and lead management dashboard designed to help teams organize prospects, track pipeline activity, monitor sales performance, and manage outreach workflows.

🔗 **Live Demo:** https://porthen-sales-intelligence.vercel.app

## Overview

Porthen provides a centralized workspace for sales teams to manage leads and monitor pipeline performance through a clean, analytics-focused dashboard.

## Features

- Sales performance dashboard with key metrics
- Lead management and prospect tracking
- Pipeline overview and lead status monitoring
- Analytics and performance visualization
- Search interface for leads, companies, and campaigns
- Responsive dashboard layout

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Supabase client
- Zustand
- Recharts
- React Router

## Project Status

The current version is a frontend dashboard with mock lead data and placeholder authentication. Backend integration and persistent data functionality are planned for future development.

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

```bash
git clone https://github.com/igbinedionelvis/porthen-sales-intelligence.git
cd porthen-sales-intelligence
npm install
```

### Run locally

```bash
npm run dev
```

### Production build

```bash
npm run build
```
